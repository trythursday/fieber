# fieber.css

fieber.css is a _classless_ and _accessible_ CSS framework. It combines semantic
markup with minimalist, brutalist, and opinionated styles.

This is Thursday's fork of fieber - it is aligned with our mission of creating
lightweight, accessible software. All credit goes to [zichy](https://github.com/zichy)
for the [original](https://github.com/zichy/fieber).

If you want to use fieber for your own purposes, please use the original directly,
and support the author! We do not promise public support for this, this is an
internal fork for convenience.
